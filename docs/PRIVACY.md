# 隐私与权限说明

本扩展不附带维护者的翻译账号、API Key，也没有项目自建的统计或中转服务器。

- **翻译数据**：悬停句子、手动选区或粘贴的文字会发送至用户选择的 DeepL / LibreTranslate。普通网页翻译不上传整页 HTML。
- **PDF**：远程 PDF 由阅读器从用户打开的 URL 获取并在浏览器内渲染，本地 PDF 在浏览器内读取；翻译时仅将捕获的文字交给翻译服务。
- **凭证**：Key 仅保存在 `chrome.storage.local`，未加密、不云同步。内容脚本接收的公开设置不含 Key；后台代为添加服务认证。
- **历史**：默认关闭；主动开启后最多保存最近 100 条原文和译文，不记录网页 URL。可以在扩展界面清空并关闭。
- **缓存**：译文缓存保存在后台内存，设置变化或后台重启后清空，可以关闭。
- **朗读和复制**：使用浏览器 / 系统的 Speech Synthesis 和 Clipboard API；语音是否联网取决于系统所提供的语音。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| HTTP(S) 全站访问 | 在普通网页捕获文字、读取在线 PDF、访问用户指定的翻译端点 |
| storage | 本地设置、Key 和用户选择开启的历史 |
| declarativeNetRequest | 将顶层 `.pdf` 导航转到 Omni PDF 阅读器，可在设置关闭 |
| contextMenus | 链接右键菜单“使用 Omni PDF 阅读器打开链接” |

浏览器设置可限制扩展的站点访问权限，限制后对应页面的翻译、PDF 读取或服务请求可能不可用。

第三方翻译服务的日志、保存期限、计费与隐私政策由服务提供者决定。用户可以使用可信的自建 LibreTranslate 服务。
