# Edge 安装与使用说明

适用版本：Omni Hover Translator 1.3.1；需要 Edge 150 或更新版本。普通使用不需要 Node.js、命令行或编译。

## 1. 下载和解压

推荐在项目 GitHub 页面右侧的 Releases 中下载 `Omni-Hover-Translator-1.3.1-Edge.zip`。不要下载浏览器扩展商店里名称相似的其他插件。

右键 ZIP → 全部解压，将其中的 `Omni-Hover-Translator-1.3.1-Edge` 文件夹保存在长期使用的位置。打开该文件夹，应直接看到 `manifest.json`、`pdf-viewer.html` 和 `vendor` 文件夹。

如果选择 GitHub 的 Code → Download ZIP 下载源码，解压后请使用仓库里的 `dist` 文件夹。不能选择仓库根目录或 `extension` 源码目录。

## 2. 加载到 Edge

1. 在 Edge 地址栏输入 `edge://extensions`，回车。
2. 开启“开发人员模式”。通常在左侧；窄窗口可先点左上角菜单。
3. 点击“加载解压缩的扩展”或“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的文件夹，点击“选择文件夹”。
5. 确认扩展卡片显示 Omni-Hover-Translator 1.3.1，开关处于开启状态。
6. 点击浏览器工具栏的拼图形扩展按钮，在 Omni 旁选择“在工具栏中显示”。

保留解压后的文件夹。浏览器以后仍然从这里读取扩展，不能装完就删。此版本采用开发人员模式安装，不会像商店扩展一样自动更新。组织管理的浏览器可能禁用此安装方式，需要管理员开放权限。

## 3. 配置翻译服务

点击 Omni 图标 → 完整设置 → 语言与翻译服务：

- **DeepL API Free / Pro**：选择自己开通的 API 套餐并填入对应 Key。申请页面：https://www.deepl.com/pro-api 。DeepL 网站会员不等于 API 会员。
- **LibreTranslate**：填写自己的或可信服务的完整 `/translate` 地址，服务要求 Key 时一并填写。支持 HTTPS 和本机 localhost / 127.0.0.1 的 HTTP。

选择源语言和目标语言，默认英语译中文。点击“保存并测试连接”，看到连接成功再使用。设置自动保存。扩展不附带他人的 Key，不提供公共免费服务，也不支持把 OpenAI Key 填入 DeepL 的输入框。

## 4. 网页翻译

刷新安装前已经打开的网页。鼠标在文字上停留约 0.2 秒，会高亮当前句子并显示译文；移到空白处后气泡自动收起。可以在气泡里复制、朗读和切换小 / 中 / 大。

选中文字可以立即翻译并固定气泡。按 Esc 或点关闭按钮收起；手动固定后需取消固定或关闭。

完整设置可调整语言、悬停等待、离开收起延时、透明度、字号、高亮和排除网站。浏览器内部页、扩展商店页面和原生 PDF 页面无法注入网页翻译。

## 5. 不动鼠标逐句阅读

在完整设置 → 阅读与朗读中开启“键盘逐句阅读”。回到文档后：

- Alt + J：下一句。
- Alt + K：上一句。
- Esc：关闭当前翻译气泡。

当前句子超出可视区时会自动滚动；网页和 Omni PDF 阅读器都适用。键盘阅读气泡保留供阅读，下一句会替换它；实际移动鼠标后恢复悬停模式和离开自动收起。输入框内不会触发。焦点应留在文档中；若网站或其他扩展拦截了按键，需要先排除冲突。

## 6. PDF 翻译

点击 Omni 图标 → PDF 阅读器 → 打开文件，选择本地 PDF。在线 HTTP(S) `.pdf` 链接默认自动进入 Omni 阅读器。无后缀链接可右键选择“使用 Omni PDF 阅读器打开链接”，或在阅读器粘贴 URL。

**浏览器自带的 PDF 阅读器不直接支持本插件翻译。** 如果看到的是 Edge 原生 PDF 工具栏，请改用 Omni 阅读器。扫描图片 PDF 没有可提取文字，本版未实现 OCR。复杂双栏文档可能需要手动划词。

## 7. 更新和排障

更新时，关闭旧阅读器，将新版本文件覆盖到原扩展目录，保持 `manifest.json` 直接位于同一级。在 `edge://extensions` 点击 Omni 的重新加载 / 刷新图标，再刷新网页并重新打开 PDF。不需要移除重装；沿用原路径可以保留本机配置。

| 现象 | 处理方法 |
| --- | --- |
| 提示缺少 manifest / 无法加载 | 检查选择的文件夹是否直接含 `manifest.json`；不要选 ZIP 或源码目录 |
| 没有开发人员模式 | 确认地址栏是 `edge://extensions`，展开页面菜单；组织策略限制需联系管理员 |
| 安装后网页没有反应 | 刷新原网页，确认总开关、网页开关、站点访问权限、排除域名和触发修饰键 |
| 设置页能打开却没效果 | 从扩展图标打开设置；不要双击本地 options.html。更新代码后要重新加载扩展和网页 |
| 服务报错 / 没有译文 | 点击“保存并测试连接”，检查 API 套餐、Key、网络、额度或自建服务地址 |
| PDF 无法打开远程链接 | 登录、防盗链和签名可能影响读取，先下载后用“打开文件” |
| 气泡不消失 | 按 Esc；查看是否划词、手动固定或仍在键盘阅读；鼠标悬停气泡需移出句子和气泡区域 |

Key 存在本机扩展存储中，不随文件包分享；翻译文字会发给你选择的服务。本地翻译历史默认关闭。
