网页 / PDF 悬停翻译、键盘逐句阅读和护眼气泡。

请下载附件 **Omni-Hover-Translator-1.3.1-Edge.zip**，解压后在 `edge://extensions` 开启开发人员模式，点击“加载解压缩的扩展”，选择直接包含 `manifest.json` 的文件夹。无需 Node.js。

安装后点击 Omni 图标 → 完整设置，填写自己的 DeepL API Key 或配置 LibreTranslate，点击“保存并测试连接”。翻译服务可能需要付费；安装包不含共享 Key。

- Alt+J / Alt+K 逐句前进和后退，需在设置开启键盘逐句阅读。
- 当前句子不完整可见时自动滚动；网页与 Omni PDF 阅读器共用。
- 气泡小 / 中 / 大三档，支持设置页或气泡直接切换。
- 键盘阅读切回鼠标后恢复自动收起。
- PDF 扫描图片需要 OCR，本版未提供；浏览器原生 PDF 页请改用 Omni 阅读器。

需要 Edge / Chrome 150+。已有用户覆盖原目录，重新加载扩展，再刷新网页 / PDF；不要移除重装。

附件中的 `.sha256` 文件可用于校验下载包。GitHub 自动生成的 Source code ZIP 是完整仓库，直接加载其中的 `dist`；扩展专用安装附件的目录更简单。
